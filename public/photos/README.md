# Upload your photos here

Drag & drop your photos into this folder using the Freebuff file panel.

## Required files

| File | Purpose |
|------|---------|
| `hero.jpg` | The faded/blended background photo behind the opening title |
| `photo-01.jpg` | Polaroid #1 |
| `photo-02.jpg` | Polaroid #2 |
| ... | ... |
| `photo-18.jpg` | Polaroid #18 |

## Notes
- Formats: JPG, PNG, or WebP all work. JPG is recommended for photos.
- Keep photos reasonably sized (under ~5 MB each) so the site stays fast.
- The 18 polaroids will automatically flow across the three conveyor belts.
- If a photo is missing, the site shows a soft peach placeholder instead.
