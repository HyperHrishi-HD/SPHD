# Upload your music here

Drag & drop your instrumental track into this folder.

## Required file

| File | Purpose |
|------|---------|
| `song.mp3` | The looping background track that autoplays on load |

## Notes
- Formats: MP3 or M4A are best. WAV works too but is much larger.
- Keep the file under ~10 MB.
- The track loops seamlessly and stops automatically when the video plays.
- It starts muted-proof: browsers require the first interaction to allow audio, so the track fades in as soon as the visitor taps/clicks/scrolls.
